# RAG University Question Answering Skill Specification

This document defines the rules, prompting guidelines, and quality standards for Antigravity AI when writing, modifying, or testing code for the **RAD-UniQA** project.

## 1. Development Principles & Coding Rules

1. **Strict Type Annotations:** Every Python function must include explicit type annotations and use Pydantic schemas for data modeling.
2. **Asynchronous Execution:** Vector database interactions, embedding generation, and LLM calls must be asynchronous (`async / await`).
3. **No Fluff Responses:** System prompts must instruct the LLM to skip conversational preambles (e.g., "Sure, here is your answer:") and begin immediately with structured Markdown headers.
4. **Equation Formatting:** All mathematical notation must use standard LaTeX markers:
   - Inline equations: `$E = mc^2$`
   - Block equations: `$$f(x) = \int_{-\infty}^{\infty} e^{-x^2} dx$$`
   - **NEVER** use raw Unicode characters for mathematical variables or operators.

## 2. Dynamic Mark-Aware Prompt Strategy

When writing prompt building routines in `src/generator/prompts.py`, adhere strictly to the target mark requirements:

```python
SYSTEM_PROMPT_TEMPLATE = """You are an expert University Examiner and Professor.
Your job is to generate a precise, academic, exam-standard answer for the given question.

TARGET MARKS: {target_marks} Marks

Context:
{retrieved_context}

Instructions based on Marks:
- IF 2-3 MARKS:
  * Maximum 150 words.
  * Provide a clear 1-2 sentence definition.
  * State the key formula or core principle in LaTeX format.
  * Give 3 distinct bullet points highlighting key parameters.

- IF 5 MARKS:
  * Maximum 350 words.
  * Section 1: Definition & Background.
  * Section 2: Working Principle or Mechanism.
  * Section 3: Summary table comparing features or pros/cons.

- IF 10 MARKS:
  * Minimum 500-600 words.
  * Section 1: Detailed Introduction & Theoretical Foundation.
  * Section 2: System Architecture / Block Diagram. You MUST construct a valid Mermaid block diagram.
  * Section 3: Step-by-step Mathematical Derivation or Detailed Algorithm Execution.
  * Section 4: Practical Example / Real-World Application.
  * Section 5: Key Advantages, Limitations, and Citations.

Citations:
Append a `### References` section at the bottom citing exact page numbers and document names.
"""
```

## 3. Mandatory Source Citation Standard

Every response generated by the RAG chain must terminate with explicitly formatted citations matching this syntax:

```markdown
### References
- **[Source 1]**: `NLP_Module_3_Notes.pdf` (Module 3, Page 14)
- **[Source 2]**: `Speech_and_Language_Processing.pdf` (Page 102)
```

If context chunks do not contain enough information to answer the question completely, the agent must output:

> **Insufficient Document Context**: The provided university documentation does not contain enough verified material to synthesize a complete answer for this question under the current syllabus filters.

## 4. Verification & Testing Protocol

When building and testing components in `src/`:
1. **Ingestion Verification:** Ensure `src/ingestion/chunker.py` correctly links child chunk IDs (`child_id`) to parent chunk IDs (`parent_id`) in Qdrant payloads.
2. **Retrieval Verification:** Verify that hybrid search in `src/retriever/hybrid_search.py` properly calculates RRF scores and does not produce duplicate chunks.
3. **LaTeX Verification:** Ensure markdown outputs parse cleanly in KaTeX rendering engines without unescaped special characters.
